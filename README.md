# MW App

A lightweight, multipurpose web utility for quick tasks.

MW App is a versatile static web application designed to help you accomplish common digital tasks directly in your browser. Perfect for anyone who needs fast, no-setup tools without installing software or creating accounts.

## Features

- Text converter (uppercase, lowercase, reverse, word count)
- Unit converter (length, weight, temperature, volume)
- JSON formatter and validator
- Color picker and palette generator
- Markdown to HTML preview
- Base64 encoder/decoder
- Random password generator
- QR code generator
